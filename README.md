# Tesla Model Y Configurator

An interactive car configurator inspired by Tesla's website.

# Features
- Switch exterior and interior colors with live image updates
- Choose wheels and Full Self-Driving option
- Total price updates automatically
- Sticky top bar that hides on scroll
- Responsive layout

# Tech Stack
HTML, Tailwind CSS, JavaScript (DOM manipulation, event delegation)
